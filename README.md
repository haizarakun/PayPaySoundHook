# PayPay Sound Hook

![version](https://img.shields.io/badge/version-1.00-blue)
![license](https://img.shields.io/badge/license-personal%20use%20only-orange)
![platform](https://img.shields.io/badge/platform-Android%20(root)-lightgrey)

PayPay の決済完了音とチャット音を、自分で選んだ音声ファイルに差し替える LSPosed モジュール。

- パッケージ名: `com.paypaysound.hook`
- 端末上の表示名: PayPay Sound module

> 本ツールは PayPay 株式会社および PayPay 関連サービスとは一切関係のない、非公式の個人開発ツールです。
> "PayPay" は各権利者の商標です。端末の中だけで動作し、PayPay 本体の APK やサーバー通信内容は一切改変・傍受しません。

## 差し替えられる音

| 対象 | 備考 |
|---|---|
| 決済完了音 | 支払いが完了したときの音 |
| チャット受信音 | PayPay のチャットのメッセージ音 |
| チャット送信音 | 同上。チャットを1通送っただけでも鳴る |

チャット音は送受金の通知専用ではないので、不要なら種類ごとに OFF にして元の音に戻せる。OFF にしても選んだ音源は消えない。

対応フォーマットは MP3 / WAV(PCM) / OGG Vorbis / AAC(M4A) / FLAC。拡張子ではなくファイルの中身から判別する。アプリ内で試聴できる。

## 動作要件

- root 化端末（Magisk / KernelSU）
- LSPosed
- Android 8.1（API 27）以上

## 導入

配布された APK をそのままインストールしてください。自分でビルドしたものは使えません（署名が違う APK は更新できず、ライセンス上も認めていません）。

1. APK をインストール
2. LSPosed Manager でモジュールを有効化し、スコープに **PayPay と本アプリ自身の両方**を追加して再起動
3. Magisk アプリの「Superuser」タブで **PayPay に root 権限を許可**
4. アプリを開いて音声ファイルを選択
5. PayPay を完全終了 → 開き直して確認

つまずくのはほぼこの2点です。

- **本アプリ自身をスコープに入れていない** → 画面の「モジュール有効」が出ない
- **PayPay に Superuser を許可していない** → 設定しても音が変わらない

音が変わらないときは、アプリ内の「診断を開く」を上から確認してください。su が通るか、モジュールがロードされているか、PayPay のバージョン、各音の状態が1画面に出ます。

## 更新

起動時に新しいバージョンがあるか確認します。見つかったときは内容を表示し、インストールするかどうか、どの方法で入れるかを選べます。

更新しても LSPosed のスコープ設定は残りますが、反映には PayPay の再起動が必要です。

## PayPay 運営の方へ

本ツールについて、事実関係を先にお伝えします。

- **個人が自分の端末で使うためのものです。** 営利目的ではなく、販売も広告も行っていません
- **PayPay アプリ本体を改変していません。** APK の再パッケージ、パッチ、クラックは一切行っていません
- **サーバーとの通信に触れていません。** 傍受、改ざん、解析、プロキシ、いずれも行っていません
- **決済の処理に関与しません。** 変更するのは効果音ファイルの読み出し先だけで、金額・残高・認証・取引履歴には一切触れません
- **端末の中だけで完結します。** LSPosed 経由で、利用者自身の端末上にある音声リソースの読み出しを差し替えているだけです
- **利用者自身の端末に限定されます。** 他人の端末やアカウントに影響する機能はありません
- **情報を収集していません。** 外部への通信は、更新確認のため GitHub に問い合わせるものだけです
